# Slotera

Многоязычный front-end MVP сервиса онлайн-записи: RU/LV/EN, расписание, услуги, публичная страница и форма бронирования без оплаты.

## Публикация на GitHub Pages

Содержимое папки можно разместить в отдельном репозитории и включить Pages из ветки `main` (root `/`). Проект не связан с Murdilimax или Cenaradar.

Сейчас бронирования сохраняются локально в браузере. Для реальной общей записи между клиентами понадобится подключить Firebase/другой бесплатный backend.
